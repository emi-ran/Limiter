# Limiter 0.14.2

## Desktop and startup
- Start Windows logon sessions in the system tray using `--tray`.
- Restore the existing window on a second launch and coordinate activation-listener shutdown.
- Improve tray icon compatibility and surface monitoring/rule-load errors during hidden startup.
- Restrict elevated startup registration to protected Program Files installations; reject portable paths, reparse points, unsafe ownership and writable dependencies.
- Preserve matching scheduled-task settings during migration and installer adoption.

## Traffic and rules
- Retain inactive process rows while explicit PID rules exist.
- Refresh parent-rule display when inherited rules change.
- Improve traffic shutdown coordination and protect unreadable rule files from accidental overwrite.

## Packaging and verification
- Verify MSI, setup EXE and portable ZIP payloads independently, including checksums and startup arguments.
- Add Windows ACL/junction regression cases and supplemental source/resource checks.
- Local verification: 15 supplemental Python checks passed; `git diff --check` passed.
- Windows compilation, runtime and installer checks are performed by the release workflow; local Linux source checks do not establish Windows runtime correctness.
